# Contributing to ATLAS Appliance

Thank you for your interest in ATLAS.

ATLAS Appliance is designed as a self-hosted, production-oriented solution.
Contributions are welcome, but must follow a strict scope and process.

## Scope of Contributions

Accepted:
- Documentation improvements
- Bug reports with clear reproduction steps
- Minor fixes aligned with existing behavior

Not accepted:
- Feature requests without prior discussion
- Architectural changes
- Support requests (use documentation instead)

## How to Contribute

1. Open an issue describing the problem clearly
2. Provide logs, context, and reproduction steps
3. Wait for validation before submitting a pull request

## Pull Request Rules

- One change per pull request
- No refactoring unless explicitly requested
- No breaking changes
- Clear commit messages required
