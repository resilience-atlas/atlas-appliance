# Code of Conduct

## Purpose

ATLAS is a professional, production-oriented project.
This Code of Conduct defines the expected standards of behavior for anyone
interacting with the project, including users, contributors, and maintainers.

The goal is to maintain a respectful, focused, and constructive environment.

---

## Expected Behavior

All participants are expected to:

- Communicate respectfully and professionally
- Focus discussions on technical facts and project goals
- Accept constructive feedback without hostility
- Respect decisions made by maintainers
- Follow documented processes and scope

---

## Unacceptable Behavior

The following behaviors are not tolerated:

- Harassment, discrimination, or personal attacks
- Aggressive or disrespectful language
- Spam, trolling, or disruptive behavior
- Repeated requests outside the project scope
- Attempts to bypass security or licensing restrictions

---

## Scope

This Code of Conduct applies to all project spaces, including:

- GitHub issues and pull requests
- Discussions and comments
- Any other communication related to ATLAS

---

## Enforcement

Project maintainers are responsible for enforcing this Code of Conduct.

Actions may include:
- Content removal
- Issue or pull request closure
- Temporary or permanent bans from participation

Decisions by maintainers are final.

---

## Reporting

If you experience or witness unacceptable behavior, you may report it privately
to the project maintainers.

---

## Final Note

ATLAS is built with a strong focus on quality, clarity, and sustainability.
Respectful collaboration is essential to achieving these goals.
