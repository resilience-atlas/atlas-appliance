# Security Policy

ATLAS applique des standards élevés de sécurité, de respect et de confidentialité.

- Toute vulnérabilité ou incident doit être signalé en privé aux mainteneurs.
- Les contributions doivent respecter la licence, le Code of Conduct et ce Security Policy.
- Aucun secret, clé ou information sensible ne doit être inclus dans les contributions.
- Les comportements contraires à la sécurité, au respect ou à la légalité entraîneront un bannissement immédiat.

Pour signaler un problème, contactez l’équipe de maintenance via les canaux privés indiqués dans le dépôt.
